# Agent zone

Machine side: Claude reads, writes and edits freely here. Nothing in this folder is a decision or a finished thought until it is copied into a human note.

- `Research/` write-ups from research tasks, one file per question: `YYYY-MM-DD <topic>.md`
- `Reports/` reviews, fact-checks, end-of-day checks: `YYYY-MM-DD <topic>.md`
- `Drafts/` text proposals to adopt, edit or discard
