Keep it current: when a note is added, moved or replaced, update its line here in the same commit.

## Folders

| Folder | What goes in | Rule |
|---|---|---|
| `Live/` | Notes that are kept up to date | Edit in place; never start a dated copy |
| `Research/` | Answers from papers and docs: why something was chosen | One note per question |
| `Reports/` | What was done or measured: test runs, diagnoses, setup plans | One note per task |
| `Explainers/` | Visual pages that explain a topic to Martyn | HTML or draw.io |
| `External/` | Reports for supervisors and professors (external-report skill) | No internal terms |
| `Archive/` | Notes replaced by a newer note or a decision | Moved, never deleted; reason listed below |

Links like `[[note name]]` find a note by name, so moving a note between folders does not break them. Plain-text paths (`Agent/…/x.md`) do break and must be updated.

Source tags in the Research list: **bib** = papers in `msc-thesis/thesis/literature.bib`, open hardware and official docs only; **wide** = also a wider web search (deep research), with sources outside the bib marked "not in bib".
