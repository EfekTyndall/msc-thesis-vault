### Demo: PICO trigger → simulated Dex1-1 (only if she asks)

Guide: `msc-thesis/docs/setup/pico-trigger-sim.md`. Before the meeting: `ssh fractal-pc 'cd ~/dex1-1-handheld && git pull'`; check IPs (PC `ip -4 addr show enp3s0`, Mac `ipconfig getifaddr en0`; 2026-11-09: PC 10.36.1.102, Mac 10.36.1.125).

1. Lab PC, start the service:
   ```
   ssh fractal-pc
   pkill -f RoboticsServiceProcess; cd /opt/apps/roboticsservice && nohup setsid bash runService.sh > /tmp/xrsvc.log 2>&1 &
   ```
2. Headset: XRoboToolkit app → enter `10.36.1.102` → status WORKING → **Tracking → Controller** on, **Data & Control → Send** on
3. Mac, Terminal tab 1 (sim; own Terminal, not a background shell):
   ```
   cd ~/dex1-1-handheld && bash software/sim/run_dex1_1.sh --udp 5005
   ```
4. Mac, Terminal tab 2 (sender on the lab PC):
   ```
   ssh fractal-pc '~/anaconda3/envs/xrobotoolkit/bin/python -u ~/dex1-1-handheld/software/xr/trigger_udp.py --host 10.36.1.125'
   ```
5. Squeeze the right trigger → fingers follow (tab 1: `received … lost 0`)
6. End: Ctrl+C in both tabs, then `ssh fractal-pc 'pkill -f RoboticsServiceProcess'`

Fallbacks: trigger stays 0 → Controller + Send on in the app · headset stuck "connecting" → ufw TCP 63901 · no headset → slider only: `bash software/sim/run_dex1_1.sh`

**Say while showing:** motion only (no collisions, picked stiffness); trigger linear 0 → open, 1 → closed; latency + trigger linearity not measured yet
