A2. Proposed handheld connections: two paths
In both paths the Dex1-1 RS-485-to-USB adapter plugs into a computer at the station, and Unitree's `dex1_1_service` runs on that computer: the motor needs a request and an answer every 2 ms (500 Hz), which cannot cross the network. Only slow gripper commands (30–90 per second) travel over the network.

- **Path 1: Raspberry Pi 5 at the station + fractal-pc.** Pi 5 with Ubuntu 24.04 LTS runs `dex1_1_service` and the camera stream (e.g. Unitree teleimager). fractal-pc stays the XRoboToolkit host: it receives the PICO pose and trigger over Wi-Fi, sends gripper commands to the Pi over the wired network, and records gripper state and camera frames. Same split as her current Pi + Jetson setup. Leaves her Jetson untouched.
- **Path 2: Jetson Orin as the single computer.** The Jetson runs `dex1_1_service`, the camera and XRoboToolkit. If XRoboToolkit and the teleop stack already run on it (A1), handheld and VR teleop share one stack, which makes the comparison easier. The adapter must plug into the Jetson, so the Jetson has to stand at the station (or be reached by a USB/RS-485 cable). It is shared with her teleop.
  - Also keeps a later mobile handheld simple: one computer that runs everything could move into a backpack with a battery (precedent ActiveUMI; [[2026-11-12 Raspberry Pi vs lab PC for the Dex1-1]]). Mobile collection is out of the current thesis scope; it would need a separate unit (not her shared Jetson) and a 24 V+ battery for the gripper.
- **Fallback:** if the Pi 5 test fails, Path 2 (Jetson as the only computer).

OS requirements for `dex1_1_service` (from the source, [[2026-11-13 dex1_1_service code and Pi 5 fit]]):
- 64-bit Linux, aarch64 (ARM) or x86-64; Unitree ships the closed motor library and DDS libraries prebuilt for both.
- Those libraries need GLIBC ≥ 2.17 and GLIBCXX ≥ 3.4.26 (C++ runtime of gcc 9 or newer). `unitree_sdk2` was prebuilt on Ubuntu 20.04, gcc 9.4.
- Unitree's tested platform: Jetson Orin NX (README); offline packages given for Ubuntu 22.04.
- **Raspberry Pi 5 is not documented by Unitree.** Ubuntu 22.04 does not support the Pi 5; Ubuntu 24.04 LTS does (Canonical). The libraries' requirements are met by 24.04, but the build and the 500 Hz loop are **untested**: a Pi 5 build test is needed first.
- Not usable: Jetson Nano (JetPack 4, Ubuntu 18.04 has GLIBCXX 3.4.25 < 3.4.26), e.g. the borrowed reComputer J1020 v2.
