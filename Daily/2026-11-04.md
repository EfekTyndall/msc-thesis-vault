## Measured / learned
From Unitree's `dex1_1_service` source and docs (not tested on hardware; [[2026-11-03 Dex1-1 technical note]]):
- State feedback at 500 Hz (one serial frame every 2000 µs), so the real path records achieved width for free; the product page says 1000 Hz.
- If commands stop, the motor switches to BRAKE mode with zero gains.
- Calibration: close the gripper by hand and run `-c` (0 to 322°, 5.62 rad).
- Position is in rad; the rad → width mapping must be measured on the gripper.
- Official URDF 261030 and STEP: about 82 mm stroke; the URDF in `dex1_1_service` (89 mm, 0.188 kg) is outdated.
- Undocumented: weight per unit as delivered, power draw, how to change a motor ID.
