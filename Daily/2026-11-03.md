I was tasked to create a mind map or any visual mapping that explains the decisions fallbacks/alternatives. Below are the discussion I did today with my Supervisor:

### [[D01 Handheld gripper body]]

Supervisor gave me an insight, that the idea of considering the UMI style workflow is because of simplicity, like collecting data without the need of teleoperating the real robot directly or combination of both workflow. So it is important to design an approach that minimize the addition of extra hardware needed, because this will contradicts with the idea. So as simple as we can get as much as possible.

The approach of using the real Dex1-1 gripper for both handheld and comes to mind. The consideration comes with the advantage and disadvantages that it gives.

#### Advantages:
- Real width data of the gripper; No encoders or markers needed ([[D05 Gripper width sensing]])
- Motor actuated gripper that could be triggered by the Pico controller
- Using the high-speed RS-485 serial communication architecture.
- No need to design gripper actuation mechanism ([[D10 Handheld mechanism]])

#### Disadvantages:
- Currently the information on how we use this RS-485 is not ye researched
- Robot unavailable during collection (will not be a problem)
- The focus shift to designing and attachment/adapter so that the Pico controller can be attached.

If using the real Dex1-1s for both real robot and hand held, more research needs to be done, such as:
- How does the RS-485 protocol works?
- What kind of computing unit do we need?
- Do we need a power supply, and how much power do we need?
- Can F/T data be acquired?
- How does the actuation with the Pico controller works?
- How do we send Pico trigger signal to the gripper through RS-485?
- Does one signal trigger closes/opens the gripper fully (0 and 1) or the gripper will closes/opens when the user holds the trigger?
- etc.

A 3D-printed copy of the Dex1-1 gripper still valuable because it doesn't cost anything. It easily can be printed on the company 3D printer and we can do some initial test while the real Dex1-1 gripper is being ordered.

The company only ordered one pair of Dex1-1, so having two extra Dex1-1 pairs is out of the option.
